title: Plot
description: A canvas chart for responses and measurements.

Use `Plot` for line, area, bar, step, point and band series on linear or log axes, with draggable markers for editing. A plot is built from its parts: axes, a grid, series, markers, a legend and a readout, each a component of its own.

<Demo name="plot" height={290} />

```tsx
import { Plot, formatters } from '@soundor/components';

<Plot width={440} height={220} title="Response">
  <Plot.XAxis domain={[20, 20_000]} scale="log" format={formatters.frequency} />
  <Plot.YAxis domain={[-24, 24]} format={formatters.decibels} />
  <Plot.Grid />
  <Plot.Area source={inputSpectrum} opacity={0.2} />
  <Plot.Line points={response} />
  <Plot.HorizontalLine value={0} />
  {bands.map((band) => (
    <Plot.Marker
      key={band.id}
      x={band.frequency}
      y={band.gain}
      onMove={([hz, db]) => moveBand(band.id, hz, db)}
    />
  ))}
  <Plot.Readout />
</Plot>;
```

Only what you put in is drawn. The smallest plot is a series:

```tsx
<Plot width={300} height={160}>
  <Plot.Line points={response} />
</Plot>
```

Without a `Plot.XAxis` or `Plot.YAxis`, that axis spans the extent of the series' static data (or 0 to 1), and draws no line or labels; the plot area takes the room. Plot draws the data it is given; analysis and other DSP belong in the plug-in.

## Parts

| Part                  | Draws                                                                       |
| --------------------- | --------------------------------------------------------------------------- |
| `Plot.XAxis`, `YAxis` | An axis's line and labels, with its `domain`, `scale`, `ticks` and `format` |
| `Plot.Grid`           | Lines at the axes' ticks, under every series                                |
| `Plot.Line`           | A line through the samples                                                  |
| `Plot.Area`           | A line, filled faintly down to its `baseline`                               |
| `Plot.Steps`          | Each value held until the next                                              |
| `Plot.Bars`           | A bar for each sample, standing on its `baseline`                           |
| `Plot.Points`         | A dot for each sample, of `radius`                                          |
| `Plot.Band`           | The region between a `lower` and an `upper` edge                            |
| `Plot.Marker`         | A point; with `onMove`, a handle to drag                                    |
| `Plot.HorizontalLine` | A level line at a y `value`, with an optional `label`                       |
| `Plot.VerticalLine`   | An upright line at an x `value`                                             |
| `Plot.Legend`         | The labelled series' names and colours                                      |
| `Plot.Readout`        | The value of each labelled series under the pointer, with a crosshair       |

A plot accepts one unnamed axis and any number of uniquely named axes per dimension. Every part belongs inside a Plot, and throws outside one.

### Independent scales

An axis takes an optional `id`, `hidden`, and `position` (`top` or `bottom`
for X, `left` or `right` for Y). A hidden axis keeps its scale without using
space for labels. Series, markers, guide lines, and grids accept `xAxis` and
`yAxis` references. Omit a reference for the unnamed axis, or, if none is
declared, the first named axis by ID. A missing explicit reference hides that
layer until its axis is available.

```tsx
<Plot width={440} height={220}>
  <Plot.XAxis domain={[20, 20000]} scale="log" />
  <Plot.YAxis domain={[-12, 12]} />
  <Plot.YAxis id="spectrum" domain={[-90, 0]} position="right" />
  <Plot.Grid />
  <Plot.Area source={spectrum} yAxis="spectrum" />
  <Plot.Line points={response} />
</Plot>
```

`usePlotCoordinates({ yAxis: 'spectrum' })` returns the usual mapping and
shared bounds, or `undefined` until that named axis is registered. The no-argument
form keeps its existing behavior. Use positive domains and samples for log axes;
non-finite mapped samples are not drawn. Give the chart an accessible label, and
provide values in controls or text when the canvas data is essential.

### Editing the plot background

<Demo name="plot-edit" height={320} />

`onBackgroundPress`, `onBackgroundDoubleClick`, `onBackgroundContextMenu`,
`onBackgroundPointerMove`, `onBackgroundPointerEnter`, and `onBackgroundPointerLeave`
are for the empty plotting area. The hit layer sits below markers and custom
interactive children, and excludes the axis margins. Decorative custom views
can opt out of hit testing with `pointerEvents: 'none'`. Provide a keyboard
alternative for actions such as adding a point.

```tsx
<Plot
  width={360}
  height={180}
  onBackgroundDoubleClick={({ data }) => addPoint(data)}
>
  <Plot.XAxis domain={[0, 1]} />
  <Plot.YAxis domain={[0, 1]} />
</Plot>
```

Each event supplies the Soundor pointer `event`, the plot-local logical pixel
`point`, default-scale `data`, and `coordinates` with bounds and conversions.
`coordinatesFor({ yAxis: 'other' })` resolves named axes. `onBackgroundDrag`
reports `start`, `move`, `end`, and `cancel` phases with a fixed `origin` and
handles cancellation on unmount. The consumer owns graph edits.

### Interactive markers

`Plot.Marker` can lock movement with `movement="x"` or `movement="y"`.
Use `constrain` to snap or bound emitted data-space values. A cancelled
gesture reports the starting point without calling `constrain`, then calls
`onMoveCancel` and `onMoveEnd`. Close host edit gestures in `onMoveEnd`.

`hitRadius` is independent of the canvas marker's `radius`. Set `selected`,
`disabled`, or provide `render(state)` to draw a non-interactive custom face.
The state contains `hovered`, `focused`, `dragging`, `selected` and `disabled`.
Styles use the `PlotMarker.root` theme slot. Set `accessibilityLabel` and
`describeValue` to identify the point and its values without changing its face.

`onSelect` handles a primary press, Enter, Space or the accessibility activate
action. `onRemove` requests removal on Delete or Backspace; the caller owns
the collection. `onWheel`, `onDoubleClick` and `onContextMenu` receive the Soundor
event. Compose a `ContextMenu.Trigger` for built-in accessibility actions, or
pass the marker's `ref` to a Popover. The example's first point moves only
horizontally, and the auxiliary value responds to the wheel.

### Selection and grouped movement

Pass `selection={{ selectedIds, onSelectionChange, multiple: true, rectangle: true }}`
to `Plot` and a stable `id` to each selectable marker. Shift, Control or Command
toggles a marker in multiple mode; Enter or Space also works on a focused marker.
Background clicks clear selection unless `clearOnBackgroundPress={false}`.
Shift-drag the background with `rectangle` enabled to replace the selection
with the markers inside the rectangle.

With `onGroupDrag`, dragging a selected marker reports the captured IDs and
`start`, `move`, `end`, and `cancel` phases instead of its individual `onMove`.
Capture application-owned starting values on `start`, then use each marker's
scale to map its original value to pixels, add `delta`, and invert. On a log
axis a common pixel displacement preserves frequency ratios. Constrain the
shared displacement before converting to data if relative spacing must be
preserved against the edges. Restore the original values on `cancel` and
close any host gestures on `end` or `cancel`.

### Series data

A series takes sorted `[x, y]` `points`, evenly spaced `values` (typed arrays work) or a live `source`: one of the three. A band takes `lower` and `upper`, or a `source` of both. TypeScript holds each series to the props it has: a `Plot.Bars` has no `strokeWidth`, a `Plot.Line` no `radius`, and `points` with `values` is refused. What gets past it (props spread from untyped data) is refused when it renders.

A series without a `color` takes the theme's voices in turn, in the order the series are drawn. One with a `label` is in the legend and the readout, unless it has `hideInReadout`.

### Order and composition

Parts are ordinary React components, so a component of yours can render them, and so can a condition or a `map`:

```tsx
function EQBands({ bands }: { bands: readonly Band[] }) {
  return bands.map((band) => (
    <Plot.Marker
      key={band.id}
      x={band.hz}
      y={band.db}
      onMove={([hz, db]) => moveBand(band.id, hz, db)}
    />
  ));
}

<Plot width={440} height={220}>
  <FrequencyAxis />
  <GainAxis />
  {showSpectrum && <Spectrum />}
  <EQResponse />
  <EQBands bands={bands} />
</Plot>;
```

Series are drawn in the order they are in the tree, the first at the bottom, however they came and went. Markers and guide lines are drawn over every series, in their own order. Everything is drawn on one canvas.

## Handles at the ends of an axis

A plot with draggable markers keeps a safe zone: its values are mapped a few pixels inside the plot area, by a handle's radius and halo, so a handle at the end of an axis is whole and never half outside the frame. The grid and axes still run edge to edge.

A series that should too, such as an EQ response, sets `extend`. Its first and last values then carry on, level, to the edges of the plot. Leave it off for data that does not continue past its ends, such as a transfer curve or an envelope.

For handles of your own, render views inside the Plot: they are laid over the canvas, in the order they come. `usePlotCoordinates()` gives a component inside a Plot its coordinates: `x.map(value)` is where a value is across, and `inner` the area the axes map to. `safeZone` on the Plot keeps them whole at the ends of the axes. [EnvelopeEditor](/docs/components/envelope-editor) is built this way.

Plot is built from the [chart helpers](/docs/utils/chart-helpers).

## Live data

A series' `source` is read when the plot draws, and each of its notifications asks for one canvas frame, with no React render. Each series has its own source, so which data is which is in the markup. See [Live plot data](/docs/guides/live-plot-data).

## Keyboard and accessibility

A marker with `onMove` is a tab stop. The arrow keys move it, and `Shift` makes the step ten times finer. Double-click or `Alt`-click (`Option`-click on a Mac) resets it, as do `Delete` and `Backspace`, and `Esc` cancels a drag. The marker is announced by its `label` (or "Point 1", "Point 2"… in the order they are drawn) with both values, such as "X 1.20 kHz, Y 4.0 dB".

The plot itself is announced as an image with its `accessibilityLabel` (the `title` if there is none), so describe what it shows. See [Keyboard and accessibility](/docs/guides/keyboard-and-accessibility).
